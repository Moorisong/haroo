# 🎨 [하루 (haroo)] 휴먼 기획서: 프론트엔드 WYSIWYG Live Builder & Dual Editing Protocol

본 문서는 **블록 조립 개선** 기획 원문에 명시된 WYSIWYG 실시간 라이브 조립 캔버스와 듀얼 인풋 에디팅 프로토콜, 그리고 Zod 단방향 0.01초 동기화 시스템에 대한 스펙을 정의하는 기획 문서입니다.

---

## 🎯 1. 목적 (Purpose)
기존의 추상적 리스트/이름표 방식(자유 텍스트 STARTER 등)을 완전히 제거하고, 캔버스에 추가하는 즉시 실제 웹사이트와 100% 동일한 디자인 컴포넌트 실물이 렌더링되며, 유저가 인풋 데이터를 직접 수정 가능한 WYSIWYG(Live Builder) 구조로 전면 개편하여 사용자 경험(UX)을 극대화합니다.

---

## 🏗️ 2. 구조 (Architecture)

### 2.1 WYSIWYG 실시간 라이브 렌더링
* **45종 마스터 블록 렌더링:** 캔버스 디바이스 프레임 내에 45종 마스터 블록이 실제 완성된 UI(Atomic 20 원자 컴포넌트 조합) 상태로 디스플레이됩니다.
* **디바이스 프레임 동적 스위칭:** 모바일(375px), 태블릿(768px), 데스크톱(1200px) 뷰포트 스위처를 통해 실시간 응답형 프레임 내 WYSIWYG 편집을 지원합니다.

### 2.2 모드 전환 및 데이터 동기화 메커니즘
* **편집 모드 (Edit Mode):** 편집 핸들러, 인라인 포커스 라인, 퀵 툴바가 활성화되어 유저의 직접 데이터 인풋 수정을 지원합니다.
* **미리보기 모드 (Preview Mode):** 상단 '미리보기' 버튼 클릭 시 모든 편집 UI가 감춰지고, 실제 배포될 완성본 웹페이지 형태로 100% 동일하게 상호작용 가능합니다.
* **Zod 데이터 단방향 동기화:** 캔버스 및 사이드 패널에서 변경된 인풋 데이터는 0.01초 내 `BlockConfig` JSON 상태에 자동 반영되며 Zod validation을 수행합니다.

### 2.3 모바일 빌더 접근 통제 및 PC 접속 유도 정책 (PC-Only Builder Access Policy)
* **모바일 접속 차단 (`MobileBlockerScreen`):** 768px 미만 실제 모바일 브라우저로 빌더(`/builder`) 페이지 접속 시, 캔버스 및 편집 UI 렌더링을 완전히 차단하고 PC 전용 접속 안내 화면을 출력합니다.
* **PC 접속 링크 복사:** 모바일 유저가 손쉽게 PC 환경으로 이동하여 작업할 수 있도록 클릭 한 번으로 접속 링크를 복사하는 기능을 제공합니다.
* **명확한 역할 분담:** 웹사이트 제작 및 세부 블록 편집은 PC(데스크톱) 전용 서비스로 단호하게 처리하고, 배포 완료된 결과물 웹페이지에 한해서 완벽한 100% 모바일 반응형 뷰를 제공합니다.

## ✨ 3. UX 규격: 듀얼 인풋 에디팅 프로토콜 (Dual Editing Protocol)

유저가 블록의 인풋 데이터(문구, 이미지, 영상, 링크 등)를 직관적으로 수정할 수 있도록 인라인 편집과 사이드 프로퍼티 패널을 제공합니다.

### 3.1 캔버스 내 직관적 인라인 편집 (In-Canvas Inline Editing)
* **텍스트 요소:** 타이틀, 본문, 버튼 문구 클릭 시 `contentEditable` 또는 팝오버 텍스트 에디터를 통해 캔버스 위에서 직접 문구를 수정합니다.
* **이미지 요소:** 캔버스 내 이미지 클릭 시 S3 업로드 드래그앤드롭 팝업 및 EXIF 회전보정 미리보기가 즉시 활성화됩니다.
* **선택 하이라이트:** 선택된 블록 외곽에 `1px indigo-500` 가이드라인 및 Floating Quick Toolbar (위/아래 이동, 복제, 삭제, 인풋 설정)가 노출됩니다.

### 3.2 사이드 프로퍼티 인풋 패널 (Side Property Controller Panel)
* **패널 오픈:** 블록(또는 Floating Toolbar의 설정 버튼) 클릭 시 우측 슬라이드 오픈.
* **제어 항목:** 텍스트 폰트/크기/색상, 배경색/그라데이션, 버튼 링크/이벤트 매핑, 비디오 URL, 폼 수집 항목 설정 등 해당 블록의 모든 인풋 데이터를 정교하게 조율합니다.

---

## 💾 4. 데이터 (Data Structure)

### 4.1 주요 블록별 실물 렌더링 & 인풋 데이터 구조 명세
* **`blk_hero_01` (히어로 배너):** 실제 메인 비주얼 이미지 + 타이틀/서브카피 텍스트 + CTA 버튼 실물 렌더링. 클릭 시 이미지/문구 즉시 변경.
* **`blk_txt_01` (자유 텍스트):** 폰트 커스텀 텍스트 실물 출력 + Floating Text Toolbar (Bold, Italic, Color, Alignment, Link) 렌더링.
* **`blk_video_01` (비디오 플레이어):** 실제 YouTube/Vimeo Iframe 및 S3 비디오 플레이어 렌더링. 사이드 패널의 Embed URL 인풋 입력창과 양방향 연동.
* **`blk_form_01` (리드 수집 폼):** 실제 input, textarea, checkbox 원자 컴포넌트 실물 렌더링. 필드 추가 및 라벨 수정 인풋 툴기 명세 포함.
* **`blk_banner_01` (배너 슬라이더):** 실제 Swiper/Slick 라이브 캐러셀 실물 렌더링. 슬라이드 이미지 추가 및 순서변경 인풋 명세.

### 4.2 유저 인풋 데이터 입력 방식 상세
* **경로 1 (캔버스 내 직접 입력):** 텍스트/타이틀 클릭 시 그 자리에서 커서 생성 후 직접 타이핑. 이미지 클릭 시 컴퓨터 파일 선택/드래그앤드롭으로 S3 1초 업로드 및 실시간 이미지 교체.
* **경로 2 (사이드 패널 입력):** 동영상 비디오 URL 붙여넣기, 리드 수집 폼 [+ 항목 추가] 버튼 클릭으로 라벨/필드 입력, 폰트/그라데이션/버튼 링크 세부 조율.
* **실시간 0.01초 반영:** 캔버스 직접 타이핑 및 사이드 패널 인풋 변경 시 즉시 (0.01초 내) 캔버스 실물 UI 반영 및 `BlockConfig` JSON 자동 실시간 동기화 저장.

## 💻 5. 구현 (Implementation)

1. **상태 관리 (`useBuilderStore`)**: 
   - 뷰포트 상태 (`desktop`, `tablet`, `mobile`), 모드 상태 (`edit`, `preview`), 선택된 블록 ID 관리.
   - 단방향 Zod 유효성 검사 기반 0.01초 데이터 업데이트 함수(`updateBlockInputData`) 구현.
2. **뷰포트 및 패널 구성 (`BuilderCanvas`, `SidePropertyPanel`, `ViewportSwitcher`)**:
   - `BuilderCanvas`: 동적 width 지원, `1px indigo-500` 포커스 스타일 적용.
   - `SidePropertyPanel`: 선택된 블록의 스키마에 동적으로 대응하는 폼 렌더링.
3. **블록 컴포넌트 (`src/components/blocks/*`)**:
   - 편집 모드 시 `contentEditable` 또는 전용 `onClick` 핸들러 부착.
   - 수정 시 스토어 함수를 호출하여 상태 즉시 동기화.
