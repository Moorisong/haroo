# 🧩 [하루 (haroo)] 원자 컴포넌트 & 마스터 블록 통합 카탈로그 (Block Catalog List)

본 문서는 `block-catalog-agent.md` 지침에 따라 하루(haroo) 프로젝트 내 현재 실제 구현되어 있는 **1계층 22종 원자 컴포넌트(Atomic Components)** 및 **2계층 35종 완성 마스터 블록(Master Blocks)**의 전체 목록, 파일명, 대표 명칭 및 세부 기능 설명을 정밀 추출하여 하나의 파일로 통합 작성한 카탈로그 문서입니다.

모든 마스터 완성 블록은 커스텀 HTML 태그를 직접 작성하지 않고 아래 22종 원자 컴포넌트를 100% 레고 조립(Composition)하여 제작됩니다.
